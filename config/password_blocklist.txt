# "password". Each entry must be at least 4 characters; shorter ones would
# reject too much.

# This is a list of what people actually reach for, not a dictionary: a
# passphrase of ordinary words is fine, a password built on one of these isn't.
# One entry per line; # starts a comment. Add to it freely.
